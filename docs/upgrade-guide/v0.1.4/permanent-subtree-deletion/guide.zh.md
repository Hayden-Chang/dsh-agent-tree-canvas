# 彻底删除子树

## 变更

Session canvas 0.1.5 的删除节点操作和 `sessionCanvas.removeNode` 会彻底删除所选 Session 及全部后代，包括会话历史、继承和生成上下文、总结、版本、摘录和草稿。旧版本仅将节点移出画布。确认框现在明确提示不可撤销，不会追溯删除以前已移出画布的 Session。

## 迁移

1. 将 0.1.5 插件包安装到现有 profile，保持同一个 `DSH_HOME` 并重启 DSH。插件启动时持有画布 Agent 的生命周期。
2. 刷新已打开的页面。使用**彻底删除**前，导出需要保留的笔记。该操作支持 DSH 0.2.2-rc.1 的原版 JSONL 存储，不修改 DSH 源码。
3. `sessionCanvas.removeNode` 的调用方应确认用户同意不可撤销删除。中途失败时重试或重启 DSH，继续持久化清理任务；重试不会恢复已经删除的数据。

完成后，子树从画布和会话列表消失，刷新后无法再读取其历史和总结。仅停用插件仍会保留数据。
